# Security

Please report vulnerabilities through [GitHub's private reporting form](https://github.com/mhadifilms/codex-hub/security/advisories/new). Include the affected version, reproduction steps, and impact. Do not include account tokens or authentication files.

Security fixes target the latest release. Codex Hub delegates execution permissions and authentication to the installed Codex CLI. Its Full access mode permits unrestricted file and network actions without approval prompts; choose a mode appropriate to your workspace.
